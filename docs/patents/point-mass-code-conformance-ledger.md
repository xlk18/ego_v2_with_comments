## 二、数学模型与代码对应

### 2.1 单轴两阶段运动

对某一坐标轴，设航段位移为 \(d\)，初速度为 \(v_0\)，末速度为 \(v_f\)，第一阶段加速度为 \(a_1\)，第二阶段加速度为 \(a_2\)，对应持续时间为 \(t_1,t_2\)。当前实现采用两段恒加速度模型：

\[
v_f=v_0+a_1t_1+a_2t_2,
\]

\[
d=v_0t_1+\frac{1}{2}a_1t_1^2+(v_0+a_1t_1)t_2+\frac{1}{2}a_2t_2^2.
\]

由速度约束得到

\[
t_2=\frac{v_f-v_0-a_1t_1}{a_2}.
\]

代入位移约束后得到关于 \(t_1\) 的二次方程

\[
At_1^2+Bt_1+C=0,
\]

其中

\[
A=\frac{a_1}{2}-\frac{a_1^2}{2a_2},\quad
B=v_0-\frac{v_0a_1}{a_2},\quad
C=-d+\frac{(v_f-v_0)(v_f+v_0)}{2a_2}.
\]

这与源文件第150—158行直接对应。第一种顺序取 \(a_1=a^+\)、\(a_2=a^-\)；第二种顺序交换二者，与第161—174行对应。判别式小于零时当前实现返回不可行标志；二次项系数为零时按一次方程处理。对每一个根恢复 \(t_2\)，仅保留 \(t_1\ge 0,t_2\ge 0\) 的组合。

### 2.2 两种切换顺序的选择

每一种加速度顺序内部，如存在两个可行根，当前实现选取总时间较小的根。若只有一个可行根，则使用该根。若两种加速度顺序均存在可行解，源代码第240—247行的比较分支返回其中总持续时间较大的顺序；该行为与通常“在所有可行顺序中取最短时间”的数学目标不完全一致。

为保持技术真实性，正式草案采用以下处理：

1. 基准实现表述为“根据预设选择准则从两个可行切换顺序中确定轴向转移方案”，不在公式层面虚构代码不存在的第三阶段运动；
2. 对“时间最优”的核心论证限定为：图搜索对由轴向求解器给定的非负边权求累计时间最小路径；
3. 将“比较两种可行顺序并选取总时间较小者”写成优选实施方式。它与现有代码只差一个比较分支方向，不应作为声称已经完成仿真验证的事实；
4. 提交前建议发明人确认该比较方向是有意设计还是实现笔误。若希望严格主张两种切换顺序范围内的轴向时间最优，源代码应同步改为选择较小总时间。

### 2.3 三轴航段时间

分别求得

\[
T_x=t_{x,1}+t_{x,2},\quad
T_y=t_{y,1}+t_{y,2},\quad
T_z=t_{z,1}+t_{z,2}.
\]

当前图搜索的边代价严格为

\[
T=\max\{T_x,T_y,T_z\}.
\]

即源文件第683—699行的行为。该步骤并未把欧氏速度上限、推力球约束、姿态角约束或障碍距离加入边代价。

### 2.4 非主导轴同步

设公共航段时间为 \(T\)，某个非主导轴的第一、第二名义加速度分别为 \(a_1,a_2\)，使用同一个缩放因子 \(\alpha\)，则同步后的约束为

\[
v_f=v_0+\alpha a_1\tau+\alpha a_2(T-\tau),
\]

\[
d=v_0\tau+\frac{1}{2}\alpha a_1\tau^2+
(v_0+\alpha a_1\tau)(T-\tau)+
\frac{1}{2}\alpha a_2(T-\tau)^2.
\]

消去 \(\alpha\) 后得到关于切换时刻 \(\tau\) 的二次方程。当前实现构造的系数经合并可写为：

\[
A_s=\frac{(v_f-v_0)(a_2-a_1)}{2},
\]

\[
B_s=d(a_2-a_1)+Tv_f(a_1-a_2),
\]

\[
C_s=a_2T\left[-d+v_0T+\frac{1}{2}(v_f-v_0)T\right].
\]

对方程 \(A_s\tau^2+B_s\tau+C_s=0\) 求根，令 \(T-\tau\) 为第二阶段时间。一般情况下缩放因子按

\[
\alpha=\frac{v_f-v_0}{a_1\tau+a_2(T-\tau)}
\]

恢复。代码还对 \(v_f=v_0\) 且两阶段时间近似相等的退化情形设置单独计算分支。当前实现计算了可能的缩放因子，但未在返回前系统地强制验证 \(|\alpha|\le 1\)；仅在上层对超界值打印调试信息。因此正式草案可以把 \(|\alpha|\le 1\) 写为理论可行性条件和优选筛选步骤，但不能声称当前代码对所有输入都已执行严格拒绝处理。

### 2.5 切换状态

若某轴第一阶段名义加速度为 \(a_1\)，则切换速度和相对起点的切换位置应为

\[
v_s=v_0+\alpha a_1\tau,
\]

\[
p_s=p_0+v_0\tau+\frac{1}{2}\alpha a_1\tau^2.
\]

源文件第91—126行分别按第一加速度方向从上下界中取 \(a_1\)，计算上述两个量。零运动轴会把时间、缩放因子、切换速度和加速度置零，并在重构时保持航点坐标不变。

### 2.6 解析轨迹重构

对任一运动轴，重构式为

\[
p(t)=
\begin{cases}
p_0+v_0t+\frac12\alpha a_1t^2,&0\le t<\tau,\\
p_s+v_s(t-\tau)+\frac12\alpha a_2(t-\tau)^2,&\tau\le t<T,
\end{cases}
\]

\[
v(t)=
\begin{cases}
v_0+\alpha a_1t,&0\le t<\tau,\\
v_s+\alpha a_2(t-\tau),&\tau\le t<T,
\end{cases}
\]

\[
a(t)=
\begin{cases}
\alpha a_1,&0\le t<\tau,\\
\alpha a_2,&\tau\le t<T.
\end{cases}
\]

源文件第701—825行分别对x、y、z轴执行同一结构。采样点数使用 \(\lfloor T/\Delta t\rfloor\)，循环条件不包含航段终止时刻，因此段末航点通常由下一段的首样本表达，最后一个终点是否显式输出取决于总序列处理。专利可描述“按采样周期生成采样时刻，并在需要时补入终点”，其中补入终点属于工程化优选，不应冒充当前循环必然行为。

## 三、分层图搜索的精确边界

设共有 \(N+1\) 个航点、\(N\) 个航段。第 \(i\) 个航点的候选速度集合为 \(\mathcal V_i\)。当前基准实施例满足：

\[
\mathcal V_0=\{\mathbf v_0\},\qquad
\mathcal V_N=\{\mathbf 0\},
\]

中间层为

\[
\mathcal V_i=\{s_k\widehat{\mathbf q}_i\mid k=1,\ldots,K\},
\quad i=1,ldots,N-1,
\]

其中 \(\widehat{\mathbf q}_i\) 是归一化参考方向，基准代码采用 \(K=20\)、\(s_k=0.5k\)。对 \(\mathbf u\in\mathcal V_i\) 和 \(\mathbf v\in\mathcal V_{i+1}\)，边权为

\[
w_i(\mathbf u,\mathbf v)=
\max_{r\in\{x,y,z\}}T_{i,r}(u_r,v_r,d_{i,r}).
\]

目标为

\[
\min_{\mathbf v_i\in\mathcal V_i}
J=\sum_{i=0}^{N-1}w_i(\mathbf v_i,\mathbf v_{i+1}).
\]

代码采用累计代价、优先队列和父节点指针进行松弛。由于图严格按航点层向前连接，也可用逐层动态规划实现完全相同的数学目标，且更容易保证每一条入边均完成比较。正式草案的伪代码采用“逐层松弛或等价的非负边权最短路径算法”，不绑定当前容器细节。

“候选集内时间最优”是可由该目标支持的准确表述；以下表述不受当前实现支持：

- 在所有连续速度函数中的绝对全局最优；
- 同时满足速度模长上限或总推力球约束的全动力学最优；
- 能耗、姿态、角速度、推力或加加速度最优；
- 重构曲线在相邻航点之间必然与输入连续几何曲线重合；
- 仅凭输入航点无条件保证与障碍物不碰撞。

## 四、主实施例与可选实施例的区分

### 4.1 可作为主实施例的内容

1. 三维质点二阶积分模型；
2. 相邻航点位置差作为航段位移；
3. 中间航点参考方向归一化；
4. 沿该方向采样多个速度幅值；
5. 起点速度固定为当前速度，终点速度固定为零；
6. 两种两阶段恒加速度切换顺序；
7. 二次方程求解和非负时间筛选；
8. 三轴独立求解后以最大轴向时间作为公共时间；
9. 对非主导轴求统一加速度缩放因子；
10. 分层图累计时间最短路径搜索；
11. 父节点链回溯；
12. 固定时间步长输出三维位置、速度和加速度。

### 4.2 只能作为可选或扩展实施例的内容

1. 在参考方向周围作锥形方向采样：源代码存在函数，但当前主搜索未调用；
2. 非零终端速度：历史版本曾设置终点速度候选，当前版本固定为零；
3. 基于时间等距或空间等距抽取上游航点：位于集成层，不属于独立算法核心；
4. 严格验证 \(|\alpha|\le1\) 并拒绝不可行边：数学上合理，但当前实现只调试提示；
5. 将最大速度作为候选集合上界：当前独立类没有单独的最大速度成员，候选上限由采样序列间接确定；
6. 对曲线走廊或障碍物进行段内碰撞复核：当前包未实现；
7. 由加速度和偏航角计算姿态：存在辅助函数，但质点轨迹输出未使用；
8. 全状态轨迹、角速度、推力优化：相关接口或注释遗留不构成当前有效工作流；
9. 加加速度连续化或滤波：当前分段恒加速度在切换点存在加速度跳变。

## 五、伪代码一致性基准

正式专利可采用下列实现无关伪代码，其核心逻辑与当前有效行为一致：

```text
输入：航点位置P[0…N]、参考方向Q[1…N-1]、初速度v_start、
      终速度v_goal、各轴加速度上下界、候选幅值集合S、采样周期dt
输出：重分配轨迹X

V[0] ← {v_start}
对 i = 1…N-1：
    q ← normalize(Q[i])
    V[i] ← {s*q | s属于S}
V[N] ← {v_goal}                  // 基准实施例取零向量

对每层节点初始化累计时间为无穷大
起始节点累计时间 ← 0
对 i = 0…N-1：
    d ← P[i+1]-P[i]
    对 u 属于 V[i]，v 属于 V[i+1]：
        对 axis 属于{x,y,z}：
            axisPlan[axis] ← SolveTwoPhase(u_axis, v_axis, d_axis, bounds_axis)
        T ← max(axisPlan[x].time, axisPlan[y].time, axisPlan[z].time)
        若 cost[u]+T < cost[v]：
            cost[v] ← cost[u]+T
            predecessor[v] ← u

optimalNodes ← 从终止节点沿predecessor回溯并反转
对 optimalNodes 中每一航段重新计算axisPlan和T：
    对每个非主导且需要运动的axis：
        axisPlan[axis] ← Synchronize(axisPlan[axis], T)
    保存该入选航段的同步参数
X ← 空序列
对 optimalNodes 中每一航段：
    按0、dt、2dt……小于航段时间的时刻，
    使用各轴两阶段恒加速度解析式计算位置、速度和加速度并追加到X
返回X
```

其中 `SolveTwoPhase` 必须说明两种加速度顺序、二次方程、非负根筛选和预设顺序选择准则；`Synchronize` 必须说明公共时间、切换时刻、缩放因子和切换状态，而不是以未定义的黑箱函数代替。

## 六、提交前必须由发明人确认的问题

1. 两种加速度切换顺序均可行时，源代码当前选择总时间较大的顺序。是否为有意避免某类速度反向/过冲，还是比较符号写反？
2. 当前中间候选速度固定为0.5—10.0，终点速度固定为零。专利主实施例可以如实写入，权利要求保持为一般候选幅值集合和预设终端速度。
3. 当前加速度缩放因子超出 \([-1,1]\) 时没有拒绝该边。仿真前应确认所用参数不会产生超界，或在程序中补充可行性过滤。
4. 当前重构轨迹不做段内障碍检测。仿真比较应同时统计最小障碍净空，不能只比较总时间。

以上问题不妨碍形成专利初稿，但会影响“时间最优”“满足加速度约束”和“保持安全性”等技术效果的最终措辞强度。
