# 质点轨迹重构算法：代码事实与专利理论一致性台账

> 本文件是内部审核材料，不属于拟提交的专利申请文件。其用途是把“现有源程序行为”与“理论正确的专利方法”分开记录，避免把实现细节、实现缺口或第三方前端误写为本发明必要特征。

## 一、共同基础

源程序与专利方法具有下列共同技术骨架：

1. 输入按顺序排列的三维航点、参考运动方向、初始速度和轴向加速度上下界；
2. 中间航点沿归一化参考方向生成多个速度幅值候选；
3. 每个航点对应一层候选速度，只连接相邻层；
4. 单轴采用两个恒加速度阶段，枚举“正界后负界”和“负界后正界”两种顺序；
5. 用端点速度和位移方程求阶段时间；
6. 通过累计航段时间选择航点速度节点链；
7. 用分段恒加速度解析式重构位置、速度和加速度。

上述骨架是从程序中提炼的方法来源。专利正文不出现类名、函数名、消息类型、话题名或文件路径。

## 二、源程序观察事实

| 环节 | 可复核的程序行为 | 不能直接推出的结论 |
|---|---|---|
| 候选速度 | 中间航点参考方向归一化后乘以0.5、1.0至10.0，共20个活动幅值 | 不代表连续速度空间已被穷尽 |
| 起止速度 | 起始层使用给定当前速度，终止层使用零速度 | 不代表理论方法只能处理零终端速度 |
| 单轴求根 | 每轴枚举两种边界加速度顺序并筛除负阶段时间 | 不代表已经从全部顺序选到较短解 |
| 两顺序比较 | 两种顺序同时可行时，现有比较分支选择总时间较大的结果 | 不符合“从全部可行顺序取最小时间”的理论定义 |
| 三轴边权 | 先求三个独立轴向时间，直接取最大值作为候选边时间 | 最大值总是下界，但未经同步验证不一定是共同可行时间 |
| 固定时间同步 | 非最大时间轴求共同缩放因子和切换时刻 | 上层提示不等于严格拒绝越界缩放因子 |
| 最大轴识别 | 对x、y、z采用严格大于比较 | 两轴或三轴并列时可能没有分支被选中 |
| 图搜索 | 使用累计代价、父节点和指针优先队列 | 节点降价后若不降键或重新入队，不能援引标准最短路径正确性 |
| 回溯 | 回溯节点链后重新求航段和同步参数 | 多根时可能选到与图边权阶段不同的参数 |
| 离散输出 | 每段普通采样数基于向下取整且循环不含段末 | 最终目标状态不一定被普通采样循环显式输出 |
| 长度补足 | 非空序列不足21点时重复最后状态 | 属于输出适配，不属于时间最优方法 |
| 测试方向 | 一组圆周示例的参考向量含非零竖直分量 | 不能无条件称其为平面圆的切向方向 |

## 三、专利采用的理论方法

### 3.1 问题域

专利把最优性限定为：固定航点顺序、有限航点速度候选、给定初末速度、各轴包含零的加速度区间，以及每轴采用共同缩放的至多一次切换两阶段控制。目标为全部航段共同持续时间之和。障碍、速度模长、刚体姿态、推力、能耗和高阶连续性不在核心问题中。

### 3.2 单轴最短时间

对单轴状态转移，实际加速度满足\(a^-\le a(t)\le a^+\)，其中\(a^-<0<a^+\)。对两个边界顺序分别求

\[
v_f=v_0+a_1t_1+a_2t_2，
\]

\[
d=v_0t_1+\frac12a_1t_1^2+(v_0+a_1t_1)t_2+\frac12a_2t_2^2。
\]

消去\(t_2\)得到

\[
At_1^2+Bt_1+C=0，
\]

\[
A=\frac{a_1}{2}-\frac{a_1^2}{2a_2},\quad
B=v_0-\frac{v_0a_1}{a_2},\quad
C=-d+\frac{v_f^2-v_0^2}{2a_2}。
\]

专利保留两种顺序的全部实数、非负阶段时间、端点残差合格解，并从合并集合中选择\(t_1+t_2\)最小者。一次退化根为\(-C/B\)，不得取绝对值。

### 3.3 共同时间

对轴\(r\)定义

\[
\mathcal F_r=\{T\ge0\mid\text{存在规定控制族内参数使该轴在T内满足端点状态和加速度界}\}。
\]

三轴独立最短时间的最大值

\[
T_{\mathrm{lb}}=\max(T_x^*,T_y^*,T_z^*)
\]

只是公共时间下界。理论边权为

\[
T_e=\min(\mathcal F_x\cap\mathcal F_y\cap\mathcal F_z)。
\]

只有在\(T_{\mathrm{lb}}\)属于三个集合时才有\(T_e=T_{\mathrm{lb}}\)。交集为空时不建立边。

固定\(T\)时，枚举\((b_1,b_2)=(a^+,a^-)\)和\((a^-,a^+)\)，求\(\tau\in[0,T]\)、\(\alpha\in[0,1]\)：

\[
v_f-v_0=\alpha[b_1\tau+b_2(T-\tau)]，
\]

\[
d-v_0T=\alpha\left[b_1(\tau T-\tfrac12\tau^2)+\tfrac12b_2(T-\tau)^2\right]。
\]

所有候选均须验证实际加速度、阶段时间和原始端点残差。分母为零时回到联立方程，不使用不定的商式。

### 3.4 图上最优

对第\(i\)层节点\(k\)和第\(i+1\)层节点\(l\)，可行边权为\(T_e(i,k,l)\)。逐层动态规划递推：

\[
g(i+1,l)=\min_k[g(i,k)+T_e(i,k,l)]。
\]

每次最小值更新同时保存前驱节点和产生该边权的可行参数。分层图无环、目标可加且跨段耦合仅由共享速度节点表达，因此递推结果是固定有限候选图内的全局最小累计时间。

### 3.5 重构

重构读取边计算阶段已经验证的参数。每一轴在切换前后分别按恒加速度积分。切换处及相邻航段航点处的位置和速度连续，加速度允许跳变。采样采用段内半开区间并显式追加最终端点。固定长度补点属于控制适配，不计入优化时间。

## 四、差异处置原则

| 差异 | 专利正文处置 | 后续工程建议 |
|---|---|---|
| 两顺序选择较长结果 | 按理论改为比较全部可行解并取最小 | 若要程序复现专利结果，应修正比较逻辑 |
| 最大轴时间未经验证即作边权 | 改为共同可行集合交集的最小值 | 建图时完成同步求解与过滤 |
| 缩放因子越界未拒绝 | 强制\(0\le\alpha\le1\)及实际加速度检查 | 把提示改为不可行返回 |
| 并列最大轴无分支 | 用集合可行性取代唯一主导轴逻辑 | 使用带容差并列处理 |
| 优先队列更新不完备 | 专利采用逐层动态规划 | 实现同样采用层序递推，或正确降键/重入队 |
| 回溯重新求根 | 保存并读取产生最优松弛的边参数 | 避免多根选择漂移 |
| 末端未显式采样 | 专利明确追加精确终止状态 | 输出阶段补入终点及时间戳 |
| 外围能力 | 从核心权利要求中删除 | 碰撞、刚体约束等作为独立下游验证 |

## 五、专利撰写边界

可以主张：

- 单轴无中间状态约束时，两种饱和切换顺序全部可行解中的最短时间；
- 给定同步控制族内，三轴可同步集合交集的最小共同时间；
- 固定有限候选速度图内，累计航段时间的全局最小值；
- 返回轨迹满足所声明的端点状态和逐轴加速度界；
- 方法独立于航点来源，可作为轨迹后处理或独立重构模块。

不得无附加证明地主张：

- 连续航点速度空间或任意控制函数中的绝对全局最优；
- 满足未建模的三维速度模长、障碍、安全走廊、推力、姿态或能耗约束；
- 加速度或加加速度连续；
- 输入几何路径安全即可推出重构轨迹安全；
- 某一第三方前端属于本发明组成部分。

## 六、仍需非理论确认的事项

以下事项不影响数学自洽性，但正式申请前必须由发明人和专利代理人确认：

1. 发明人名单及各自创造性贡献；
2. 申请主体、公开时间和是否存在影响新颖性的在先披露；
3. 现有技术检索结果及最接近现有技术；
4. 独立权利要求是否保留“共同缩放两阶段控制族”作为必要特征；
5. 附图的正式绘制、术语法律审校和权利要求层级；
6. 仿真数据、参数、公平对比方案和能够支持的效果表述。
