# 质点时间重分配专利理论整改设计

## 1. 整改目标

对 `docs/patents/point-mass-time-reallocation-patent-draft.md` 进行实质审核和重写，使专利公开的是一套自洽、可证明且能够独立实施的质点轨迹时间优化方法，而不是对当前程序状态的逐行说明。专利正文不讨论“已实现”“未实现”“当前代码缺陷”或具体程序接口；工程实现与理论方法之间的差异只记录在内部审核报告中。

## 2. 理论适用域

本方法的最优性限定在以下问题域内：

1. 质点满足三维二阶积分模型 `p_dot=v`、`v_dot=a`；
2. 三个坐标轴的控制彼此解耦，每轴具有包含零的有限加速度区间；
3. 输入为固定顺序的空间航点、各中间航点的参考速度方向、初始速度和终端速度；
4. 各中间航点速度从有限候选集合中选择；
5. 每一轴在一个航段内采用至多一次切换的两阶段恒加速度控制，两个阶段的实际加速度均位于该轴加速度区间内；
6. 目标函数为全部航段公共持续时间之和；
7. 不包含速度模长上限、障碍物、安全走廊、完整刚体动力学、姿态、推力、能耗或高阶连续性约束。

在该问题域内，“时间最优”是有限航点速度候选图和上述航段控制族内的全局最优，不宣称任意连续速度、任意控制曲线或完整飞行器动力学下的绝对全局最优。

## 3. 理论正确的航段模型

### 3.1 单轴最短时间

对单轴状态转移 `(p0,v0) -> (pf,vf)`，控制满足 `a_minus <= a(t) <= a_plus`，其中 `a_minus<0<a_plus`。由最短时间双积分器的极值结构，候选最优控制只需检查：

- 先使用 `a_plus`，再切换至 `a_minus`；
- 先使用 `a_minus`，再切换至 `a_plus`。

对每一种顺序，根据末速度与位移约束得到关于第一阶段时间的二次方程，保留所有实数且两个阶段持续时间均非负的根。单轴最短时间必须从两种顺序的全部可行根中取 `t1+t2` 的最小值，不能采用固定顺序优先级，也不能选择较长解。

### 3.2 公共时间可行集合

对第 `r` 轴定义可同步时间集合：

`F_r = {T >= 0 | 存在切换顺序、tau in [0,T] 以及界内的两阶段实际加速度，使该轴在T内满足端点位置和速度}`。

若采用共同缩放系数，则实际加速度为 `alpha*a1` 和 `alpha*a2`，并严格检查实际加速度分别落在 `[a_minus,a_plus]` 内。`F_r` 也可以通过直接求两个阶段的实际加速度构造，只要不超出加速度区间。

三维候选边的理论正确代价为：

`T_edge = min(F_x intersect F_y intersect F_z)`。

令三个单轴最短时间为 `T_x*、T_y*、T_z*`，则 `T0=max(T_x*,T_y*,T_z*)` 只是公共时间的下界。仅当 `T0` 同时属于三个可同步时间集合时，才有 `T_edge=T0`。若某个非主导轴在 `T0` 不可同步，应继续寻找大于 `T0` 的最小共同可行时间，而不是直接输出越界缩放因子或错误删除本来在更长时间下可行的边。

### 3.3 静止轴和退化状态

- 当轴向位移、初速度和末速度均为零时，零加速度保持状态，因此任意非负公共时间均可行；
- 当轴向位移为零但初末速度并非均为零时，不得直接按静止轴处理，仍须进行可行时间求解；
- 二次项退化时按带符号的一次方程求根，不能对负根取绝对值；
- 判别式、时间、加速度和端点残差均使用尺度化容差；
- 多轴最短时间并列不会产生歧义，因为公共时间由可行集合定义；重构时每个在该时间上使用饱和单轴解的轴均可视为主导轴。

## 4. 图搜索与全局最优性

每个航点对应一层候选速度节点，只连接相邻层。对每一候选边完整计算 `T_edge`；无共同可行时间的边不存在。图为有向无环图，边权为非负且只依赖该航段位移和两端候选速度。

使用逐层动态规划：

`g(i+1,l)=min_k [g(i,k)+T_edge(i,k,l)]`。

同时保存达到最小值的前驱节点和该边的可行两阶段参数。由于目标函数可加、状态耦合只通过共享的航点速度节点表达，Bellman最优性原理保证终点代价是有限候选图内的全局最小累计时间。无需使用存在降键问题的可变优先队列。

## 5. 轨迹重构要求

1. 对选中边使用边权计算阶段已经验证的两阶段参数，不再用另一套方程重新生成可能不一致的参数；
2. 每一轴的位置和速度在切换点连续；
3. 相邻航段共享同一航点位置和同一候选速度，因此航点处位置、速度连续；
4. 加速度允许在轴内切换点和航点处跳变，不声称加速度或加加速度连续；
5. 离散输出显式包含整个轨迹的最终状态；
6. 采样点补足属于控制接口适配，不属于时间最优方法的必要步骤。

## 6. 专利文本整改范围

### 6.1 标题与摘要

保留标题《一种基于时间重分配的质点时间最优轨迹生成方法》。摘要明确有限候选集合、共同可行时间和分层图动态规划，不再把三轴时间最大值无条件等同于公共可行时间。

### 6.2 权利要求

- 重写独立权利要求1，使候选边代价由三轴可同步时间集合交集确定；
- 单轴从属权利要求明确遍历两种切换顺序的全部可行根并选择最短者；
- 同步从属权利要求严格限定切换时刻和实际加速度界；
- 图搜索从属权利要求限定逐层动态规划和前驱记录；
- 删除未形成核心闭环的速度换向检测、位移方向检测和多选式异常处理；
- 删除或降级与核心发明无关的方向锥、安全走廊、完整动力学、滚动规划等内容；
- 系统、设备和存储介质权利要求与整改后的方法权利要求逐项对应。

### 6.3 说明书

重新组织为：技术问题、严格问题定义、单轴最短时间证明、公共时间可行性、分层图全局最优性证明、轨迹重构、边界条件、伪代码和实施例。凡出现“保证”“最优”“可行”均检查其前提条件。

### 6.4 仿真章节

只保留以下内容：

- “仿真验证说明（预留）”标题；
- 一句说明EGO-Planner仅为对照前端，不属于本发明；
- 参数表、结果表和图号占位；
- “结果分析待填写”和“仿真结论待填写”。

删除尚未实际执行的实验步骤、指标结论倾向和长篇仿真方法描述。
